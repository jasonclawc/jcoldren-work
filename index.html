Objects for workplace practice.

Three working prototypes built around practice, feedback, recall, and support at the moment of need.

TRAINING OS Command Center Modules / XP / Knowledge Checks / Agent Stats

ID-001 / TRAINING OPERATIONS SYSTEM

Training Command Center

A browser-based training hub for onboarding agents: curriculum map, trainer schedule, resource library, XP tracking, knowledge checks, module completion, and optional backend sync planning.

Learning need
Give new hires one place to understand the path, practice core topics, and track progress.
Methods
Performance support, spaced retrieval, knowledge checks, dashboard feedback.
Artifact
Open prototype
SIMULATOR First Shift Scenario Practice / Coaching / XP / Consequences

ID-002 / SOFTWARE SIMULATION

ACE Adventure Simulator

A standalone practice environment where learners click through a simplified CRM workflow, handle cases, use templates, make escalation decisions, and receive coaching when they choose the wrong path.

Learning need
Move CRM training from passive slides into realistic procedural practice.
Methods
Branching scenarios, coach tips, guided discovery, feedback loops.
Artifact
Open prototype
GAME-BASED LEARNING Football 101 Coach Mode / Decision Points / Rules Practice

ID-003 / GAME-BASED TRAINING

Football 101 Coach Mode

A lightweight interactive game that teaches football concepts through coaching prompts, scoring, immediate feedback, and repeated decision-making rather than static explanation.

Learning need
Help support learners recognize game situations and explain football basics with confidence.
Methods
Game loop, scenario prompts, rule reinforcement, score-based motivation.
Artifact
Open prototype
